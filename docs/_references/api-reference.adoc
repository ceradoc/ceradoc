= API Reference

== Purpose

Complete API documentation for Ceradoc's public interface.

== Core Module

=== Ceradoc

The main Ceradoc module provides the primary API for parsing and converting documents.

[source,ruby]
----
module Ceradoc
  VERSION: String

  # Parse an AsciiDoc string
  def self.parse(input, **options) -> Ceradoc::Model::Document

  # Parse an AsciiDoc file
  def self.parse_file(filename, **options) -> Ceradoc::Model::Document

  # Convert a document to a format
  def self.convert(document, to:, **options) -> String
end
----

== Core Methods

=== Ceradoc.parse(input, **options)

Parse an AsciiDoc string into a document model.

[source,ruby]
----
signature: parse(input, **options) -> Ceradoc::Model::Document
----

*Parameters:*

* `input` (String) - AsciiDoc string to parse
* `schema` (Symbol) - Schema to use for parsing (`:default`, `:iso`, custom)
* `strict` (Boolean) - Whether to raise on parse errors (default: `false`)
* `preserve_whitespace` (Boolean) - Preserve whitespace in text (default: `false`)
* `attributes` (Hash) - Default document attributes

*Returns:* `Ceradoc::Model::Document`

*Raises:* `Ceradoc::ParseError` if parsing fails and `strict: true`

*Examples:*

[source,ruby]
----
# Basic parsing
doc = Ceradoc.parse("== Title\n\nContent")

# With schema
doc = Ceradoc.parse(input, schema: :iso)

# With attributes
doc = Ceradoc.parse(input, attributes: { "author" => "John Doe" })

# Strict mode
begin
  doc = Ceradoc.parse(input, strict: true)
rescue Ceradoc::ParseError => e
  puts "Parse error: #{e.message}"
end
----

=== Ceradoc.parse_file(filename, **options)

Parse an AsciiDoc file into a document model.

[source,ruby]
----
signature: parse_file(filename, **options) -> Ceradoc::Model::Document
----

*Parameters:*

* `filename` (String) - Path to AsciiDoc file
* `schema` (Symbol) - Schema to use for parsing
* `strict` (Boolean) - Whether to raise on parse errors
* `preserve_whitespace` (Boolean) - Preserve whitespace
* `attributes` (Hash) - Default document attributes
* `encoding` (String) - File encoding (default: `"UTF-8"`)
* `base_dir` (String) - Base directory for include resolution

*Returns:* `Ceradoc::Model::Document`

*Raises:* `Ceradoc::ParseError`, `Errno::ENOENT` (file not found)

*Examples:*

[source,ruby]
----
# Basic file parsing
doc = Ceradoc.parse_file("document.adoc")

# With encoding
doc = Ceradoc.parse_file("document.adoc", encoding: "ISO-8859-1")

# With base directory for includes
doc = Ceradoc.parse_file("main.adoc", base_dir: "/path/to/docs")
----

=== Ceradoc.convert(document, to:, **options)

Convert a document model to a specified format.

[source,ruby]
----
signature: convert(document, to:, **options) -> String
----

*Parameters:*

* `document` (Ceradoc::Model::Base) - Document model to convert
* `to` (Symbol) - Target format (`:adoc`, `:html`)
* `indent` (Integer) - Output indentation (default: `0`)
* `line_width` (Integer, nil) - Maximum line width (default: `nil`)
* `sort_attributes` (Boolean) - Sort attributes alphabetically

*Returns:* String output in specified format

*Raises:* `Ceradoc::SerializationError` if serialization fails

*Examples:*

[source,ruby]
----
doc = Ceradoc.parse("= Title\n\nContent")

# Convert to AsciiDoc
asciidoc = Ceradoc.convert(doc, to: :adoc)

# Convert with formatting
asciidoc = Ceradoc.convert(doc, to: :adoc, indent: 2, line_width: 80)

# Write to file
File.write("output.adoc", Ceradoc.convert(doc, to: :adoc))
----

== Model Classes

=== Ceradoc::Model::Base

Base class for all model elements.

[source,ruby]
----
class Ceradoc::Model::Base
  # Serialize to AsciiDoc
  def to_adoc(**options) -> String

  # Convert to format
  def convert(to:, **options) -> String
end
----

=== Ceradoc::Model::Document

Root document container.

[source,ruby]
----
class Ceradoc::Model::Document < Base
  attr_accessor :header        # Ceradoc::Model::Header
  attr_accessor :document_attributes  # Ceradoc::Model::DocumentAttributes
  attr_accessor :sections       # Array<Ceradoc::Model::Section>
end
----

=== Ceradoc::Model::Section

Document section with title and content.

[source,ruby]
----
class Ceradoc::Model::Section < Base
  attr_accessor :title          # Ceradoc::Model::Title
  attr_accessor :sections       # Array<Ceradoc::Model::Section> (nested)
  attr_accessor :paragraphs     # Array<Ceradoc::Model::Paragraph>
  attr_accessor :blocks         # Array<Ceradoc::Model::Block::Core>
end
----

== Configuration

=== Ceradoc.configure

Configure global settings.

[source,ruby]
----
Ceradoc.configure do |config|
  config.default_schema = :iso
  config.strict = false
  config.parser.warn_on_undefined = true
end
----

=== Ceradoc.debug

Enable/disable debug mode.

[source,ruby]
----
Ceradoc.debug = true  # Enable debug output
Ceradoc.debug = false # Disable debug output
----

== Input Conversion

=== Ceradoc::Input::HTML.convert

Convert HTML to Document Model.

[source,ruby]
----
signature: Ceradoc::Input::HTML.convert(html) -> Ceradoc::Model::Document
----

*Parameters:*

* `html` (String) - HTML string to convert

*Returns:* `Ceradoc::Model::Document`

*Examples:*

[source,ruby]
----
html = "<h1>Title</h1><p>Content</p>"
doc = Ceradoc::Input::HTML.convert(html)
asciidoc = doc.to_adoc
----
